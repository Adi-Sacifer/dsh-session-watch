session-watch: verify the INSTALLED copy loads, not just the repo

A real near-miss: the installed copy under the profile's node_modules was missing
diagnose.js and archive.js, which the new index.js imports. A restart would have loaded a
plugin that could not resolve its own imports, and the first symptom would have been a dead
watchdog - the same silence as a healthy system.

So the installed bytes now get their own check (test/verify-installed.mjs, 13 assertions):
every dependency file is present, the module imports, apply() runs, one timer starts, three
routes register, the session and injection subscriptions are made, and no warning is logged.
It skips cleanly when nothing is installed, so it never blocks the suite elsewhere.

Seven suites, 160 assertions, run in both the repo and the installed skill directory.
